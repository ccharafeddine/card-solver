# Card Solver 1.0.0

First release.

- **Poker:** equity vs random hands or painted ranges (exact or Monte Carlo), outs with exact odds, pot odds and implied odds, a fold/call/raise EV table (simple model), preflop seat charts, and a game-theory panel (EV, pot odds, ranges, MDF and bluffing, GTO).
- **Blackjack:** exact EV of every action for any rules, a live house edge, a strategy chart, a trainer with accuracy stats, and Hi-Lo counting with the Illustrious 18.
- Spotlight tour with live examples and 13 lessons.
- Four looks, light and dark; works offline; Windows installer.
